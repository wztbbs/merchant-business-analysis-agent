# 下架因子 · 分析思路与结论话术

## 分析思路
1. 先在 sku_status_log 中确认该 SKU 在观察期内是否真实发生下架事件，以及当前在架状态。
2. 若确认下架：用基线期日均销售估算下架造成的直接损失（直接损失 = 基线期销售额 − 当前期销售额），
   再除以整体指标变化量得到贡献率，判断它是不是本次下滑的主因。
3. 同时看同品类其他 SKU 的销量变化，评估替代效应：如果替代品销量明显上涨，说明需求部分被承接，实际净损失小于直接损失。
4. 若查不到下架记录，说明用户假设不成立，应在结论中明确指出，而不是强行归因。

## 结论话术要点
- 主结论：「{sku}」于 {delisting_time} 下架，销售变化 {sales_delta} 元（负值即直接损失），占整体变化的 {contribution_ratio}。
  （{sku} 等处引用 step_results 中的实际取值，不要照抄本话术中的示例商品名。）
- 替代效应：同品类其他商品销售变化 {substitution_effect}，需求承接有限/明显。
- 建议：评估恢复上架或引入同价位替代 SKU，并观察一周销售数据。
