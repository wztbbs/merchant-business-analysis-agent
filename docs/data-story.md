# 演示数据明细（种子数据故事）

支撑 demo 问题「为什么上个月销售额下滑了，跟下架的无糖可乐有关吗？」：

- 30 个 SKU；「无糖可乐」(sku01, 饮料) 是热销品，前月每天约 300 件；
- 无糖可乐在上月 15 号下架 → 下半月销售归零，是下滑贡献最大的单一 SKU（贡献率约 29%）；
- 其余 SKU 上月销量约为前月的 80%，整体销售额环比下滑约 23%；
- 前月 10~20 号有一档「满50减10」活动，上月无活动（活动空窗）；
- 上月曝光/进店 UV 约为前月的 85%（次要因素）；sku15 上月 5~9 号有一次缺货事件；
- sku08（巧克力）自上月 1 号起涨价 15% 并延续到当月（价格因子正例）；
- 当月 1 号到生成当天也有数据（销量延续上月水平），保证 this_month 查询非空。

日期全部基于 `LocalDate.now()` 相对计算，任何时候启动「上月/前月」都有数据。
注意：种子只在 order_item 为空时生成一次，当月数据不会逐日增长；要最新当月数据就删库重启重造。
